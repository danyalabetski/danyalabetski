### Snip

**Smart Screenshot Organizer · iOS**

A privacy-focused screenshot manager that automatically analyzes and organizes screenshots directly on the device.

**Built with:** `Swift` · `SwiftUI` · `Vision` · `OCR` · `Photos`

### Findly

**AI-powered Place Discovery · iOS**

A location-based application that turns natural-language requests into a single relevant place recommendation instead of overwhelming users with lists and maps.

**Built with:** `SwiftUI` · `Supabase` · `Foursquare` · `Gemini`

## Development Approach

I care about more than simply making an application work.

**Architecture**
Scalable structures, separation of concerns, reusable components and maintainable code.

**Performance**
Efficient data handling, asynchronous operations and responsive interfaces.

**UX**
Interfaces should be simple, intuitive and purposeful.

**Product thinking**
Features should solve real problems and contribute to the overall product experience.

**Privacy**
Whenever possible, sensitive processing stays on-device rather than being unnecessarily sent to external services.
